# 결과 CSV 요약

CSV 파일의 숫자 열마다 최솟값, 최댓값, 평균을 계산해 JSON으로 돌려준다.

## 언제 쓰나

- 사용자가 결과 CSV를 요약하거나 비교해 달라고 할 때

## 실행

이 스킬 폴더의 `scripts/summarize_csv.py`를 쓴다. 스크립트를 프로젝트의 `scripts/`로 복사하지 말고 이 위치에서 바로 실행한다.

```text
python <이 스킬 폴더>/scripts/summarize_csv.py <CSV 파일> [결과 JSON 파일]
```

결과 JSON 파일을 주지 않으면 표준 출력으로 내보낸다.

## 실패 판정

- 종료 코드가 0이 아니면 실패다. 오류 문구를 사용자에게 그대로 알린다.
- 숫자 열이 하나도 없으면 실패로 끝난다. 다른 파일을 읽었을 수 있으니 경로를 확인한다.
