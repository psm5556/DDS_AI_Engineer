# 결과 숫자 정리

해석 결과의 숫자를 보고서나 표로 옮길 때 이 순서를 따른다.

## 언제 쓰나

- 사용자가 결과를 표로 정리하거나 보고서에 넣어 달라고 할 때
- 여러 케이스의 결과를 비교할 때

## 순서

1. 숫자마다 단위를 확인한다. 모르면 추측하지 말고 어디서 나온 값인지 먼저 찾는다.
2. 같은 표 안에서는 단위를 하나로 맞춘다. 응력은 MPa, 길이는 mm를 기본으로 한다. 사용자가 정한 단위가 있으면 그것을 따른다.
3. 유효 숫자는 3자리로 맞춘다. 원본 값은 지우지 않고 그대로 둔다.
4. 바꾼 단위가 있으면 표 아래에 적는다.

## 하지 말 것

- 단위를 모르는 값을 환산하지 않는다.
- 숫자가 이상해 보여도 혼자 고치지 않는다. 어떤 값이 왜 이상한지 사용자에게 알린다.
