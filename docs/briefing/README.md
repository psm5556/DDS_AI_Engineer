# 경영진 보고 자료

DDS AI Engineer를 경영진에게 쉽게 설명하는 자료다.

| 파일 | 쓰는 곳 |
|---|---|
| `DDS_AI_Engineer_경영진보고.html` | 발표용 슬라이드 7장(브라우저로 바로 연다). 지금 방식과 비교하고, 드럼세탁기·스마트폰 사례를 움직이는 데모로 보여 준다 |
| `DDS_AI_Engineer_경영진보고.pptx` | 이전 판 11장(브래킷 경량화 사례). 발표자 노트가 들어 있고, 도형은 PowerPoint에서 바로 고칠 수 있다 |

## HTML 슬라이드 쓰는 법
- 넘기기
  - → 키·Space·PageDown: 다음 장면. 장면을 다 보면 다음 장으로 넘어간다(PPT 애니메이션과 같다).
  - ← 키: 이전 장면.
  - 프레젠터 리모컨도 같은 키를 보내므로 그대로 쓸 수 있다.
- 기능 키
  - F: 전체 화면
  - P: 자동 재생/멈춤
- 아래 막대의 다음 버튼에는 다음에 일어날 일이 적혀 있다(예: "승인하고 계산").
- 각 장의 내용

  | 장 | 주제 | 내용 |
  |---|---|---|
  | 1 | 표지 | 한 문장 요약과 흐름 |
  | 2 | 비교 ① 걸리는 시간 | 세탁기 문제를 지금 방식과 동시에 출발시키는 경주 |
  | 3 | 데모 ① 드럼세탁기 | 앱 화면을 흉내 낸 부탁 → 계획 → 승인 → 60개 계산 → 결과. 데모 화면의 '계획 승인' 버튼을 눌러도 넘어간다 |
  | 4 | 데모 ② 스마트폰 낙하 | 낙하 장면과 3D 시뮬레이터. 슬라이더 두 개를 발표 중에 직접 움직일 수 있다 |
  | 5 | 비교 ③ 일이 끝난 뒤 | 흩어지는 파일과 쌓이는 자산. 다른 제품으로 넓히는 예시 |
  | 6 | 안심 | 회사 안 그림, 사람 승인 |
  | 7 | 다음 단계 | 현황과 부탁드리는 것 |

- 숫자: 모든 숫자는 이해를 돕기 위한 예시다. 해당 장에 "예시" 표시가 있다.
  - 예: 2주 → 2일, 흔들림 38% 감소, 충격 115% → 89%
  - 시범 운영에서 실제 값으로 바꾼다.
- 색의 뜻: 주황 = 사람이 하는 일, 청록 = AI 조수가 하는 일.
- 사내망에서 웹 글꼴을 못 받으면 맑은 고딕으로 보인다.

## 고쳐서 다시 만들기
- HTML: `src/briefing_body.html`(본문)을 고친 뒤 위의 html 파일에도 같은 내용을 반영한다.
  - 앞부분(title·style)은 `<head>`에, 나머지는 `<body>`에 넣는다.
- PPTX(이전 판):
  1. `cd docs\briefing\src; npm install` — pptxgenjs를 받는다. 사내 npm 미러를 쓴다.
  2. `node make_assets.mjs` — 아이콘·브래킷 그림을 PNG로 만든다. `frontend`의 playwright-core와 설치된 Edge를 쓴다.
  3. `node build.js` — `..\DDS_AI_Engineer_경영진보고.pptx`를 다시 만든다.
- `korean_wrap.py`는 PPTX에서 한글이 글자 중간에서 줄바꿈되는 문제를 고친다(build.js가 자동으로 부른다).
  - 원인: pptxgenjs가 글자에 중국어 문자 집합을 붙여서 생긴다.
