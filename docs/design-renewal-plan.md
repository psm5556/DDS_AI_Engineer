## 1. 목표와 원칙

### 1-1. 목표
- 사내 CAE 엔지니어(프로)가 처음 열어도 깔끔하고 믿음이 가는 화면을 만든다. 설명 없이 쓸 수 있어야 한다.
- 기능은 바꾸지 않는다. 글자·색·간격·상자·움직임 같은 겉모습의 규칙만 하나로 정리한다.
- 갤러리 사례는 대부분 홍보용 사이트다. 큰 첫 화면이나 스크롤 연출 같은 배치는 가져오지 않는다. 우리는 업무용 앱이므로 **시각 언어**만 가져온다.

### 1-3. 사례에서 뽑은 공통 패턴과 우리 결정
| # | 공통 패턴 | 우리 앱에서 정한 것 |
|---|---|---|
| 1 | 산세리프 하나로 UI를 쓰고, 숫자·코드는 따로 다룬다 | **Pretendard 하나만** 쓴다(이미 `pretendard` 패키지로 앱에 들어 있음).<br>숫자는 `tabular-nums`(자릿수 정렬)로 보인다.<br>코드는 시스템 고정폭 글꼴을 쓴다. |
| 2 | 제목은 자간을 좁히고, 본문은 기본 자간 | 16px 이상 제목: −0.01 ~ −0.03em<br>본문: 0 |
| 3 | 무채색에 강조색 하나. 주 버튼은 아껴 쓴다 | 파랑은 다음 네 곳에만 쓴다.<br>- 한 화면의 **주 동작 1개**<br>- 선택 상태<br>- 링크<br>- 진행 표시 |
| 4 | 상자 테두리보다 바탕색 차이로 구분하고, 선은 아주 옅게 | **상자 속 상자를 없앤다.**<br>구획은 바탕 톤 차이와 머리글, 옅은 구분선으로 나눈다.<br>테두리 상자는 하나의 물건일 때만 쓴다(결과 카드, 흐름도 단계, 입력창). |
| 5 | 둥글기는 작게, 상태 태그만 알약 모양 | 지금 18가지인 둥글기를 **5단계**로 줄인다. |
| 6 | 그림자는 떠 있는 것에만 | 카드에는 그림자를 넣지 않는다.<br>메뉴·팝오버·알림·모달에만 넣는다. |
| 7 | 움직임은 짧고 절제한다 | 시간은 3단계(120·180·240ms)와 감속 곡선 하나만 쓴다.<br>'움직임 줄이기' 설정을 지킨다. |
| 8 | 제품을 결과로 보여 준다(번호 단계, 상태 태그, 진행 표시) | **'1단계' 번호**를 흐름도·단계별 결과·대화 카드·보고서에 같은 모양으로 붙인다. |
| 9 | 다크 모드는 같은 토큰 이름에 다크 값만 바꾼다 | 이미 있다. 다만 값이 두 파일에 나뉘어 있으니 한 파일로 모은다. |
| 10 | 큰 글자 한 줄, 짧은 설명, 동작 1~2개 | **첫 화면과 로그인 화면에만** 쓴다. 작업 화면에는 쓰지 않는다. |

### 1-4. 지금 앱의 상태
근거: 코드와 `frontend/e2e/shots/`의 스크린샷

**좋은 점**
- Pretendard가 앱에 들어 있다.

**고칠 점**

| 문제 | 근거 |
|---|---|

| 값이 제각각이다 | 글자 크기 20가지(10~40px, 0.5px 단위도 섞임)<br>둥글기 18가지<br>토큰 밖 hex 색 52가지 |

| 기준 스크린샷이 낡았다 | 옛 이름(DDS AI Engineer)과 옛 '결과' 탭이 찍혀 있다.<br>개편 전에 다시 찍어 기준으로 삼는다. |

## 2. 디자인 토큰 개편안
- 모든 값은 `frontend/src/design/tokens.css` 한 곳에 둔다.
- `modern.css` 맨 앞의 `:root` 재정의는 이 파일로 옮긴다.
- 토큰 이름은 지금 쓰는 이름(`--ink`, `--paper`, `--panel`, `--line`, `--brand` …)을 그대로 쓴다. 바뀌는 것은 값과 새 단계 토큰뿐이다.

### 2-1. 글꼴
| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--font` | `"Pretendard Variable", Pretendard, "Malgun Gothic", "Apple SD Gothic Neo", sans-serif` | 전체 |
| `--font-mono` | `"Cascadia Mono", Consolas, "D2Coding", monospace` | 코드·경로·스크립트 |
| 숫자 | `font-variant-numeric: tabular-nums` | 표, 핵심 수치, Simulator 예측값, 진행 숫자 |

- Pretendard(OFL)는 npm 패키지로 빌드에 포함된다. 따라서 사내망에서 외부 웹 글꼴을 받을 일이 없다. 불러오지 못하면 맑은 고딕으로 보인다.
- 새 글꼴 파일은 추가하지 않는다.
  - 보고서 제목용 세리프(예: 마루부리, OFL)도 검토했지만 넣지 않는다.
  - 문서다운 느낌은 쪽 폭, 줄 간격, '그림 1.' 번호로 낸다.

### 2-2. 글자 크기 단계 (20가지 → 7단계)
| 토큰 | 크기 / 줄 간격 | 굵기 · 자간 | 쓰는 곳 |
|---|---|---|---|
| `--fs-11` | 11 / 1.4 | 500 · 0 | 그래프 눈금, 보조 캡션 |
| `--fs-12` | 12 / 1.45 | 500 · 0 | 메타 정보, 칩, 표 머리, 사이드바 묶음 이름 |
| `--fs-13` | 13 / 1.5 | 400 · 0 | 사이드바, 표 본문, 캔버스 본문 |
| `--fs-14` | 14 / 1.6 | 400 · 0 | 대화 본문, 입력창, 보고서 본문 |
| `--fs-16` | 16 / 1.4 | 600 · −0.01em | 구획 제목, 카드 제목(큰) |
| `--fs-20` | 20 / 1.3 | 650 · −0.02em | 화면 제목(설정·Simulator) |
| `--fs-28` | 28 / 1.25 | 700 · −0.03em | 첫 화면·로그인 한 줄, 핵심 수치 |

**무채색** (`modern.css`의 따뜻한 회색 방향을 정식 값으로 삼는다)

| 토큰 | 라이트 | 다크 | 뜻 |
|---|---|---|---|
| `--paper` | `#fbfbfa` | `#191918` | 앱 바탕 |

**강조색과 의미색** (값은 지금과 같고, 쓰는 곳만 줄인다)

| 토큰 | 라이트 | 다크 | 쓰는 곳 |
|---|---|---|---|
| `--brand` | `#2563eb` | `#3b82f6` | 주 동작 1개, 선택, 링크, 진행 막대, 포커스 |
| `--brand-soft` | `#eef3fe` | `rgb(59 130 246 / .14)` | 선택 행, 강조 태그 바탕 |
| `--warn` / `-soft` | `#b45309` / `#fffbeb` | `#fbbf24` / 12% | **엔지니어 확인이 필요한 것**(승인 대기, 실행 확인)<br>소개 슬라이드의 '주황 = 엔지니어 일'과 같은 뜻이다. |
| `--ok` · `--err` · `--info` | 지금 값 | 지금 값 | 완료, 실패, 안내 |
| `--mean` · `--sigma` · `--epi` | 지금 값 | 지금 값 | 데이터 의미(평균, 산포, 불확실도) |

- 색만으로 뜻을 전하지 않는다. 상태에는 항상 아이콘이나 글자를 함께 붙인다.
- 토큰 밖 hex 색을 52개에서 0개로 줄이는 것이 목표다. 점검 방법은 4절 6단계에 있다.

### 2-4. 여백·둥글기·그림자·움직임
| 종류 | 토큰 | 값 | 쓰는 곳 |
|---|---|---|---|
| 여백 (4px 단위) | `--sp-1 … --sp-7` | 4 · 8 · 12 · 16 · 24 · 32 · 48 | `gap`, `padding`에만 쓴다. 바깥 여백(margin)은 줄인다. |
| 둥글기 | `--r-xs` | 4 | 체크박스, 인라인 코드 |
| | `--r-s` | 6 | 버튼, 입력칸, 작은 칩 |
| | `--r-m` | 10 | 카드, 결과, 흐름도 단계 |
| | `--r-l` | 14 | 대화 입력창, 모달 |
| | `--r-pill` | 999 | 상태 태그, 단계 번호 |
| 그림자 | `--shadow-card` | `none` | 카드 |
| | `--shadow-pop` | 라이트: `0 8px 24px rgb(0 0 0/.08), 0 1px 2px rgb(0 0 0/.06)`<br>다크: 알파 3배 | 메뉴, 팝오버, 알림 |
| | `--shadow-modal` | 지금 값 | 모달 |
| 움직임 | `--dur-fast` | 120ms | 마우스 올림, 누름 |
| | `--dur` | 180ms | 펼침, 탭 전환 |
| | `--dur-slow` | 240ms | 패널 열고 닫기 |
| | `--ease` | `cubic-bezier(.22,1,.36,1)` | 전체 |

- `prefers-reduced-motion: reduce`에서는 움직임 시간을 모두 0으로 한다.

## 3. 화면별 개선안

### 3-1. 로그인 (앱의 첫인상)
- **왼쪽**: 큰 글자 한 줄(`--fs-28`)과 흐름 그림을 둔다.
  - 그림: 요청 → AI 계획 → 승인 → 실행 → 보고서
  - 정적 SVG로, 소개 슬라이드 색과 같게 한다.
- **오른쪽**: PIN 입력 하나만 둔다.
- 움직임과 배경 그라디언트는 넣지 않는다.

### 3-2. 첫 화면
- 대화 입력창을 화면의 중심에 둔다(Claude 데스크톱 방식).
- 위에는 인사 한 줄(`--fs-28`)과 설명 한 줄을 둔다.
- 지금의 번호 붙은 세 칸(프로젝트 이름, 작업 폴더, 할 일)을 바꾼다.
  - 이름과 폴더는 입력창 아래 '옵션' 한 줄로 접는다.
  - 비워 두면 자동으로 정해지므로 단계가 줄어든다.
- 빠른 시작 칩은 4~5개만 두고, 아이콘과 글자만 보인다(테두리 옅게).
- 최근 프로젝트는 상자 없는 목록으로 둔다: 한 줄에 이름, 상태 태그, 시각. 줄 사이에는 옅은 구분선만 둔다.

### 3-3. 작업 공간 (사이드바 · 대화 · 캔버스)
| 영역 | 개선 |
|---|---|
| 사이드바 (256px) | 바탕은 `--side-bg`이고, 테두리 대신 톤 차이로 구분한다.<br>항목은 높이 32px, 글자 `--fs-13`<br>상태 점: 승인 대기는 `--warn`, 실행 중은 `--brand` |
| 머리줄 | 경로 표시(프로젝트 / 대화)와 캔버스 열기 버튼 하나만 둔다.<br>높이 48px, 아래는 옅은 선 |
| 대화 열 | 본문 폭은 최대 720px로 가운데 둔다.<br>내 메시지만 말풍선(`--bubble`)이고, AI 답변은 말풍선 없이 본문으로 보인다.<br>도구 기록은 '작업 N건 ✓' 한 줄로 접는다. |
| 대화 카드 | 작업 흐름 카드와 실행 확인 카드만 테두리 상자로 둔다.<br>승인이 필요한 카드는 왼쪽에 `--warn` 아이콘을 붙인다. 띠 장식은 쓰지 않는다. |

### 3-5. Simulator

계획과 다르게 적용한 곳
- 로그인의 흐름 그림: 정적 SVG 대신 번호 붙은 태그 목록(토큰 색·글자 크기를 그대로 쓰려고)
- 케이스 표 머리 색: 입력은 `--brand-soft`, 출력은 `--mean-soft`(`--panel-2` 대신. 데이터 탭의 입력·출력 표시와 같은 색)
- 보조 버튼 테두리: `--line-strong` 대신 `--line`(`--line-strong`은 입력칸에만. 버튼이 많은 화면에서 선이 너무 진해서)
- 카드 둥글기: `.panel`·`.block`·결과·대화 카드는 10이고, 예전에 14로 적힌 일부 상자(툴 분야 묶음 등)는 그대로 14다

적용하지 않고 남긴 곳
- 여백 토큰(`--sp-*`): 새로 쓴 규칙에만 썼다. 기존 규칙의 px 여백은 그대로다.
- 움직임 토큰: 버튼·입력·탭 등 주요 요소에만 썼다. 기존 규칙의 다른 전환 시간은 남아 있다.
- 단계 번호: 흐름도와 단계별 결과는 번호와 상태 표시를 따로 둔다(대화 카드만 번호가 체크로 바뀐다).
- 관리 화면: 탭 + 표 구조라 두 열 배치로 바꾸지 않았다.
- 파일 탭 트리: 지금의 폴더 이동 목록을 유지했다(세로선만 없앴다).

### 8-3. 알아 둘 함정
- `@keyframes`는 시작만 정한다. 기본 CSS가 최종 모습이어야 움직임을 꺼도 내용이 보인다.
- 대화의 내 메시지는 임시 id로 붙었다가 서버 id로 바뀐다. 키가 바뀌므로 임시일 때만 등장시킨다(`ChatView.tsx`).
- `canvas-body key={tab}`은 탭마다 다시 만들어진다. 투명도만 움직인다(Plotly·흐름도 크기를 흔들지 않게).
- `ReactFlow key={perRow}`: 폭이 바뀌면 다시 만들어지므로 패널 폭을 움직이지 않는다.
- `.react-flow__node`는 인라인 transform을 쓴다. 움직임은 안쪽 `.flow-node`에.
- `getComputedStyle`이 `800ms`를 `0.8s`로 돌려줄 수 있다. 시간 토큰은 `motion.ts`의 `ms()`로 읽는다.
- 고정폭 글꼴에 한글이 없어 대체 글꼴로 나오고, 띄어쓰기만 넓어 보인다. 한글 머리말에는 `word-spacing: -.28em`.
- 지역 CSS 변수는 토큰 검사에 걸린다(`--c, --p, --canvas-w, --cv-w, --side-col, --cv-col`만 허용).
