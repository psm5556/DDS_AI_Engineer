# FloSCRIPT 템플릿 만들기

## 절차
1. 사내 Flotherm GUI에서 기준 프로젝트를 연다.
2. FloSCRIPT 녹화를 시작한다. TODO(사내검증): 메뉴 위치(버전별).
3. 바꿀 값을 한 번씩 바꾼다(부품 power, 히트싱크 핀 높이, 팬 유량 등). 객체는 **트리에서 이름으로 선택**한다.
4. 해석을 실행하고, 결과 표(부품 온도 요약)를 CSV로 내보낸다. 파일 이름만 쓴다(상대 경로).
5. 프로젝트를 저장하고 녹화를 끝낸다.
6. 녹화된 XML에서 바꾼 숫자를 `{{cpu_power}}`처럼 바꾸고 `<이름>.xml.tmpl`로 저장한다.
7. `run_script`로 `flotherm_prepare.py --run --require component_temps.csv`를 한 번 실행해 확인한다.

## 규칙
- 플레이스홀더는 **속성 값 안에만** 넣는다(`new_value="{{cpu_power}}"`). 태그 이름이나 구조에는 넣지 않는다.
- `flotherm_prepare.py`는 값을 XML 이스케이프(`& < > "`)하고 렌더 결과를 `xml.etree`로 검사한다.
- 같은 객체 이름이 여러 개면 선택이 모호해진다. 기준 프로젝트에서 객체 이름을 고유하게 정리한다.
- 녹화 스크립트에 절대 경로(프로젝트 경로, 내보내기 경로)가 들어가면 `{{project_name}}`이나 상대 경로로 바꾼다.
