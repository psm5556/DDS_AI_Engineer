# nCode DesignLife 배치 연동 메모

## 플로 준비 체크리스트 (GUI에서 한 번)
1. FE 입력 글리프: FE 결과 파일(.op2/.odb/.rst …)을 **케이스 폴더 기준 상대경로**로 지정하거나, 저장 뒤 .flo에서 경로를 `{{__case_dir__}}/bracket.op2`로 바꾼다.
2. 하중 입력: ASCII 시계열이면 `--scale-csv`로 배율을 바꿀 수 있다. 바이너리(.s3t)면 플로의 배율 속성을 쓴다.
3. 분석 글리프(SN/EN 등)의 숫자 속성 중 설계변수를 독특한 값으로 넣고 저장 → .flo에서 검색 → `{{name}}`.
4. 출력: 엔티티별 손상/수명 표를 케이스 폴더 아래(예: `out/damage.csv`)에 CSV로 쓰게 한다.
5. GUI에서 한 번 실행해 CSV가 생기는지, `ncode_extract.py --csv out/damage.csv --list`로 열이 인식되는지 확인한다.

## 결과 지표 고르기
| 목적 | results 키 | 비고 |
|---|---|---|
| 최악 위치 손상 | `max_damage` | 1 이상이면 목표 수명 안에 파손 |
| 최소 수명 | `min_life`, `log10_min_life` | 최적화에는 로그값 권장 |
| 목표 대비 여유 | `life_margin` | `--target-life` 필요 |
| 파손 영역 크기 | `n_damage_ge_1` | |
| 임계 위치 | `critical_id` | 위치 비교용(회귀 대상은 아님) |
